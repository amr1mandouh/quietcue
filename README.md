# QuietCue

QuietCue is a quiet show board for small theatre productions. Track every cue in a show, mark cues as called, filter by cue type or priority, and keep a show selected while you move between views.

## Getting started

    npm install
    npm run dev

Useful checks:

    npm test
    npm run typecheck
    npm run build

Data is saved locally in the browser. No network or account is required.
